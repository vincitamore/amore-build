# Current state

> Dynamic state. **The session that changes reality updates this file before it
> ends.** Standing reality only - keep a re-readable word budget (~6,000 words,
> the lineage ceiling matching `iris regula lint`'s `CURRENT_STATE_MAX_WORDS`;
> raise deliberately when the house justifies it, never silently).
>
> **What this is:** the shared handoff between sessions - facts that remain true
> until contradicted, plus what is actively in flight.
>
> **What this is not:** a task list, an inbox, a changelog dump, or a place for
> doctrine (schemas and disciplines live in [[AGENTS]]). Point at work with
> paths; do not paste whole task bodies here.
>
> **Entry lifecycle** (the lineage convention - the iris dash's Recent Changes
> panel renders these): (1) new session changes land under
> `## Recent structural changes (DATE)` as a bold-lead paragraph compressed to
> the standing fact + wikilink; (2) when the work completes or is superseded,
> compress the entry to ≤3 lines in the same breath; (3) when a dated section
> ages past ~21 days or the file exceeds ~6,000 words, migrate whole sections
> verbatim to `context/previous-state.md` (append-only, newest-first) - `iris
> regula lint`'s current-state-staleness rule warns, the in-session agent moves.
